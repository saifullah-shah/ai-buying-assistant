# Research Log

Add one entry per meaningful external-research task. This log should separate factual evidence from recommendation and assumptions.

## Entry template
- ID:
- Research question:
- Checked on (UTC):
- Scope/market/category:
- Primary sources and direct URLs:
- Claims directly supported by sources:
- Unknowns / limitations / conflicting sources:
- Inference or recommendation (clearly labelled as inference):
- What needs testing directly:
- Decision affected:
- Status: `OPEN` / `PARTIAL` / `VERIFIED` / `SUPERSEDED`

## Research standards
- Prefer official docs, terms, API references, standards, and primary research.
- For changing facts, record the date checked and revisit before implementation.
- Open cited pages and verify they actually support the claim; search snippets are not enough.
- Distinguish "documented capability" from "we successfully tested access".
- Distinguish "an API exists" from "our account is approved and may use it for this purpose".
- Distinguish "data is visible on a page" from "we are allowed to collect, retain, display, or republish it".
- Do not write guesses into code or decision docs as facts.
